# Kun tartibim

Namoz vaqtlariga moslangan kun tartibi, duolar va tasbeh, aql mashqlari, xarajatlar hisobi va uy ko'rsatishlar. Internetsiz ishlaydi, eslatmalarni bildirishnoma qilib yuboradi.

## APK ni yuklab olish
Har safar kod yangilanganda GitHub o'zi APK yig'adi. Tayyor faylni **Releases** bo'limidan `KunTartibim.apk` nomi bilan yuklab olasiz.

## Kompyuterda yig'ish (ixtiyoriy)
Android Studio da shu papkani oching va **Build → Build APK(s)** ni bosing.
